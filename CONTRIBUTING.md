# Contributing

The contributor guide is [documentation/Contributing.md](documentation/Contributing.md): where to start for each kind of change, how to run only the website, and what to check before requesting review. Matching rules and new datasets start in the engine's own guide, [CONTRIBUTING.md in the engine repository](https://github.com/openTdataCH/osm-public-transport-matcher/blob/main/CONTRIBUTING.md).

When you open a pull request, fill in the change contract of the [pull request template](.github/pull_request_template.md). [Before requesting review](documentation/Contributing.md#before-requesting-review) lists what to check first.
