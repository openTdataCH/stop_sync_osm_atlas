A Swiss route ID contains the timetable year (-j26-), and the year is ignored when IDs are compared. The rest of an ID can still change from one year to the next, and an ID can pass to another line, often one with the same number in another town, so an ID of another year links two lines only when they also have the same number and share a stop. A line linked to another OSM line usually means that this OSM line carries an outdated ID that now belongs to a different line. Every OSM line counted here was also compared with the GTFS lines of its mode and number, without a clear match by stops.
