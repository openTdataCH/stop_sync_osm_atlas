# A2 Web app

The website lets reviewers explore the published snapshot: where ATLAS and OpenStreetMap agree, where they differ and why. This chapter describes its pages and the shared mechanisms behind them.

| Layer | Technology |
|---|---|
| Browser | Leaflet maps and plain JavaScript modules, Bootstrap; all libraries served locally ([A3.4](3.4%20Frontend%20asset%20management.md)) |
| Server | Flask: server-rendered pages and a JSON API (`backend/blueprints/`), of which only `/api/lookup` is public ([A2.10](2.10%20Public%20API.md)) |
| Data | PostgreSQL with PostGIS ([A1](1.%20Database%20%26%20bundle%20import.md)) |

## Pages

| Page | Path | Shows | Details |
|---|---|---|---|
| Map | `/` | Every matched and unmatched stop of the viewport, with filters, search and a live summary | [A2.1](2.1%20Map%20data%20loading%20and%20rendering.md), [A2.2](2.2%20Filter%20and%20search%20logic.md), [A2.3](2.3%20Global%20statistics.md) |
| Problems | `/problems` | One problem at a time, by priority, with the stops involved on a map | [A2.4](2.4%20Problems%20page.md) |
| Routes | `/routes`, `/routes/non-gtfs`, `/routes/gtfs-stop-id-sloid` | Matched and unmatched lines with their variants, OSM routes outside the timetable, and the GTFS identity map | [A2.6](2.6%20Routes%20pages.md) |
| Operators | `/operators` | For each ATLAS operator, how its matched OSM stops are tagged with `operator` and `operator:wikidata`, as a list of values with counts and map links, and a consistency status | [A2.7](2.7%20Colours%20and%20styles.md#operator-tag-status) for its colours |
| Data | `/data/analytics`, `/data/export` | Statistics of the published snapshot and the live pipeline timeline; CSV and PDF exports | [A1.2](1.2%20Statistics%20and%20timestamps.md#the-sections-of-statsjson), [A3.5](3.5%20Pipeline%20progress.md), [A2.5](2.5%20Reports%20and%20PDFs.md) |
| Docs | `/docs` | This documentation | [A2.8](2.8%20Documentation%20portal.md) |

The map, Problems and Routes pages keep what they show in the address bar, so it can be shared as a link ([A2.9](2.9%20Permalinks.md)). Scripts and AI agents read the same stops as JSON through the public lookup, `/api/lookup`, and learn how from `/llms.txt` ([A2.10](2.10%20Public%20API.md)). Every page polls the pipeline status, so the navigation bar shows when a run is in progress. Which source labels and views appear is set by the review configuration and the active bundle's capabilities ([A3](3.%20Application%20architecture%20%26%20deployment.md#presentation-configuration-and-matching-policy)).
