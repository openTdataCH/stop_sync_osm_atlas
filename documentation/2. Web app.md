# A2 Web app

The website lets reviewers explore the published snapshot: where ATLAS and OpenStreetMap agree, where they differ and why. This chapter describes its pages and the shared mechanisms behind them.

| Layer | Technology |
|---|---|
| Browser | Leaflet maps and plain JavaScript modules, Bootstrap; all libraries served locally ([A3.4](3.4%20Frontend%20Asset%20Management.md)) |
| Server | Flask: server-rendered pages and a JSON API (`backend/blueprints/`) |
| Data | PostgreSQL with PostGIS ([A1](1.%20Database.md)) |

## Pages

| Page | Path | Shows | Details |
|---|---|---|---|
| Map | `/` | Every matched and unmatched stop of the viewport, with filters, search and a live summary | [A2.1](2.1%20Map%20Data%20Loading%20and%20Rendering.md), [A2.2](2.2%20Filters%20and%20Search%20logic.md), [A2.3](2.3%20Global%20Stats.md) |
| Problems | `/problems` | One problem at a time, by priority, with the stops involved on a map | [A2.4](2.4%20Problems%20Page.md) |
| Routes | `/routes`, `/routes/non-gtfs`, `/routes/gtfs-stop-id-sloid` | Matched and unmatched lines with their variants, OSM routes outside the timetable, and the GTFS identity map | [A2.6](2.6%20Routes%20Pages.md) |
| Operators | `/operators` | For each ATLAS operator, how its matched OSM stops are tagged with `operator` and `operator:wikidata`, as a stacked breakdown with a consistency status | [A2.7](2.7%20Colours%20and%20styles.md#operator-tag-breakdowns) for its colours |
| Data | `/data/analytics`, `/data/export` | Statistics of the published snapshot and the live pipeline timeline; CSV and PDF exports | [A3.3](3.3%20Background%20Scheduler.md#live-status-in-the-web-interface), [A2.5](2.5%20Generate%20Reports%20and%20PDFs.md) |
| Docs | `/docs` | This documentation | [A2.8](2.8%20Documentation%20Page%20Delivery.md) |

Every page polls the pipeline status, so the navigation bar shows when a run is in progress. Which source labels and views appear is set by the review configuration and the active bundle's capabilities ([A3](3.%20System%20Architecture.md#presentation-configuration-and-matching-policy)).
