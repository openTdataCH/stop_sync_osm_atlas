# 7.2 Backend tests

This repository runs Python unit tests for the backend API logic using **pytest**.

## Scope of tests

The tests are located in `tests/backend/`.
They validate the various endpoints and logic within the backend app:

- Endpoints response status codes and body structure
- Map bounds operations
- Session management and permissions
- Interaction with the User Input Database (`user_input_db`)

## Running the tests

Like other test suites, prioritize running the backend tests inside the Docker container to mimic the CI environment perfectly.

```bash
docker-compose run --rm app-dev bash -c "python -m pytest tests/backend/ -v"
```

## Creating new tests

If you add new endpoints or utility methods in `backend/`, ensure that matching tests are implemented in `tests/backend/test_backend.py`. You can utilize the shared mocked data and resources configured in `tests/conftest.py`.
