## ATLAS data

### Public view
ATLAS provides the authoritative list of public-transport traffic points in Switzerland. We focus on actual boarding platforms with valid data today and ensure each point lies inside Switzerland’s precise border. The result is a clean CSV that downstream steps can trust.

What we keep:
- Switzerland only (country code 85) and inside the official boundary polygon
- Entries that are still valid today (`validTo` in the future)
- Only `BOARDING_PLATFORM` elements (the places where passengers board)

What we produce:
- `data/raw/stops_ATLAS.csv` (semicolon-separated), ready for GTFS/HRDF integration and OSM matching

### Developer view
- Source: `https://data.opentransportdata.swiss/en/dataset/traffic-points-actual-date/permalink`
- Implementation: `Download_and_process_data/get_atlas_data.py:get_atlas_stops`

Key filters and rationale:
- `uicCountryCode == 85`: Switzerland’s UIC country code
- Precise CH polygon using `geo_utils.filter_points_in_switzerland(df, 'wgs84North', 'wgs84East')`
- `validTo >= today` using ISO string comparison to preserve `9999-12-31` infinity semantics
- `trafficPointElementType == 'BOARDING_PLATFORM'`

Code excerpt (filters and export):
```python
with z.open(csv_filename) as f:
    df = pd.read_csv(f, sep=";")
    df = df[df['uicCountryCode'] == 85]
    df = filter_points_in_switzerland(df, lat_col='wgs84North', lon_col='wgs84East')

    # validTo: compare as ISO strings to keep 9999-12-31
    today_iso = datetime.date.today().isoformat()
    valid_to_iso = df['validTo'].astype(str).str.slice(0, 10)
    df = df[valid_to_iso >= today_iso].copy()

    # Only boarding platforms
    if 'trafficPointElementType' in df.columns:
        df = df[df['trafficPointElementType'] == 'BOARDING_PLATFORM'].copy()

    df.to_csv(output_path, sep=";", index=False)
```

Precise Switzerland filter:
```python
def filter_points_in_switzerland(df: pd.DataFrame, lat_col: str, lon_col: str) -> pd.DataFrame:
    df = df.dropna(subset=[lat_col, lon_col]).copy()
    df[lat_col] = pd.to_numeric(df[lat_col], errors='coerce')
    df[lon_col] = pd.to_numeric(df[lon_col], errors='coerce')
    df = df.dropna(subset=[lat_col, lon_col])

    swiss_poly = _load_swiss_polygon()
    gdf = gpd.GeoDataFrame(
        df,
        geometry=gpd.points_from_xy(df[lon_col], df[lat_col], crs='EPSG:4326'),
    )
    inside_or_border = gdf.intersects(swiss_poly)
    filtered = gdf[inside_or_border].drop(columns='geometry')
    return pd.DataFrame(filtered)
```
