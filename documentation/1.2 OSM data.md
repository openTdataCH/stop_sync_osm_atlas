## OSM data

### Public view
We fetch public transport nodes from OpenStreetMap across the whole of Switzerland and also fetch the routes that reference those nodes. From the raw XML, we produce two easy CSVs: one lists node–route pairs (with direction when available), the other lists each route with its nodes.

What we keep:
- PT nodes such as `public_transport=platform/stop_position/station/halt/stop`
- Also nodes tagged `highway=bus_stop`, `railway=tram_stop|halt|station`, `amenity=ferry_terminal|bus_station`, `aerialway=station`
- All `route` relations that reference those nodes

What we produce:
- `data/raw/osm_data.xml` (raw Overpass output)
- `data/processed/osm_nodes_with_routes.csv` (node–route pairs, optional `direction_id`)
- `data/processed/osm_routes_with_nodes.csv` (route+direction → list of node_ids)

### Developer view
- Overpass endpoint: `http://overpass-api.de/api/interpreter`
- Implementation: `Download_and_process_data/get_osm_data.py`

Overpass query (Switzerland area + PT nodes + their routes)
```19:37:Download_and_process_data/get_osm_data.py
query = """
[out:xml][timeout:180];
area["ISO3166-1"="CH"]->.searchArea;
(
  node(area.searchArea)["public_transport"~"platform|stop_position|station|halt|stop"];
  node(area.searchArea)["railway"="tram_stop"];
  node(area.searchArea)["amenity"="ferry_terminal"];
  node(area.searchArea)["amenity"="bus_station"];
  node(area.searchArea)["highway"="bus_stop"];
  node(area.searchArea)["railway"="halt"];
  node(area.searchArea)["railway"="station"];
  node(area.searchArea)["aerialway"="station"];
);
out;
(
  relation(bn)[type=route];
);
out meta;
"""
```
