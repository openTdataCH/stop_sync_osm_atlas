# A4.3 Code quality

This page shows the latest code-quality evidence for both repositories. The
module catalog (`quality/modules.yml` in each repository) assigns every source
file to one responsibility and records its risk, entry points, invariants,
documentation and tests. The result bundle connects engine and application
modules through a declared contract.

`make quality-fast` checks deterministic local correctness. `make quality` runs
the supported isolated environment, including both repositories, browser tests,
producer/consumer compatibility and real PostGIS publication tests. The generated
report records revisions, source fingerprints and raw evidence; absent and stale
measurements stay visible. See [the quality guide](https://github.com/openTdataCH/stop_sync_osm_atlas/blob/main/quality/README.md) for setup,
context packets, baselines and the remaining rollout stages.
