# 0.1 Using the map

The map shows every ATLAS platform and every OSM stop element, and joins each matched pair with a line.

## Markers and lines

| Marker or line | Meaning |
|---|---|
| Dark blue circle | An ATLAS platform with an OSM match |
| Green circle | An OSM element with an ATLAS match |
| Red circle | An ATLAS platform without an OSM match |
| Grey circle | An OSM element without an ATLAS match |
| Hollow grey ring with **U** | A [disused OSM element](0.5%20Glossary.md#disused-osm-element), such as `disused:highway=bus_stop`; it is never matched |
| Solid line | A match |
| Dashed green line | Parts of one [OSM stop unit](0.5%20Glossary.md#osm-stop-unit), such as a platform and its stop position |

One ATLAS platform can be matched to two OSM nodes, its platform and its stop position. The **Legend** button in the lower left corner explains the markers, lines and letters, and the zoom at which each appears.

## Zoom

Zoomed out, the map shows only the red ATLAS platforms without a match; zoom in to see every stop. A banner says when the map shows only part of the stops. The layer button switches the base map between OpenStreetMap, Transport and Satellite.

## Search

The box *Search stop name or ID...* takes a stop name, a [UIC number](0.5%20Glossary.md#uic-number) (`8503000`), a [SLOID](0.5%20Glossary.md#sloid) (`ch:1:sloid:3000:501:33`), an OSM node (`node/123456789`) or a route (`route:11-T-j25-1 dir:0`). Each search becomes a filter chip.

## The popup

Click a marker to open its popup. It shows the ATLAS and OSM fields side by side, the distance and the [match type](0.5%20Glossary.md#match-type), which names the evidence for the match; its info icon opens the rule. **(view on ATLAS)**, **(view on OSM)** and **Edit in OSM iD Editor** open the stop elsewhere, **Routes** lists the lines that serve it, and **See Matches** compares a matched pair field by field.

## Filters

Options ticked in one group add up; different groups must all hold.

| Filter | Shows |
|---|---|
| **Matched** | Matched pairs, all or by [matching rule](0.5%20Glossary.md#matching-rule) |
| **Unmatched** | Stops without a match. *No OSM < 50m* means no OSM stop within 50 m; *OSM < 50m* means OSM stops are near, but none was matched |
| **OSM**, then **OSM Groups** | OSM elements grouped into one stop: a platform with its stop position, or a two-sided stop |
| **ATLAS**, then **Duplicate ATLAS** | ATLAS platforms that share a UIC number and platform code |
| **Problems** | Stops with a problem of the chosen types and priorities |
| Operators | Stops of the chosen ATLAS or OSM operators |
| **Top N Distances** | The N matched pairs farthest apart |
| **Random** | A random stop that fits the filters |

The summary at the top right counts the stops that fit the filters. **Clear all** removes the filters and **Copy link** copies the view.
