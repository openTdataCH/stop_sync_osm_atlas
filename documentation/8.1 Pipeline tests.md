# 8.1 Independent Engine Tests

The matching tests live in `engine/tests/` and install no Flask or SQLAlchemy dependency. The engine package contains its own pytest configuration and synthetic fixtures.

```bash
python -m pip install -e './engine[swiss,gtfs,acquisition,test]'
python -m pytest engine/tests -q
```

For only the normalized in-memory API and predicate regressions, install `./engine[test]` and run `engine/tests/test_api.py` and `engine/tests/test_matching_regressions.py`.

Tests cover exact/name/distance/route predicates, ordered stages, source duplicate and OSM pair/trio propagation, independent runs, namespace-safe references, valid zero coordinates, co-located elements, missing route evidence, adapter parsing and the result writer. Source downloads are mocked; no national dataset or live network is needed.

Database import tests belong to the review app. The former small-pipeline SQLite test mocked spatial and transaction operations; it has been replaced by bundle contract tests and actual PostGIS publication tests. See [CI and tests](8.%20Test.md).
