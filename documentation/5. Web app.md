# Web Application

The Stop Sync web application provides an interactive map interface for exploring and managing the ATLAS–OSM matching data.

## Architecture

| Layer | Technology | Purpose |
|-------|------------|---------|
| Frontend | Leaflet + Vanilla JS | Map rendering, user interaction |
| Backend | Flask (Python) | API endpoints, business logic |
| Database | PostgreSQL + PostGIS | Spatial queries, data persistence |

## Frontend Components

### Map (Leaflet)

- **Tile Layers**: OpenStreetMap, Transport Map, Satellite
- **Markers**: ATLAS (green), OSM (orange), matched pairs (both)
- **Clustering**: Overlapping markers offset for visibility
- **Popups**: Detailed stop information on click

### Zoom-Based Rendering

| Zoom | Mode | Behavior |
|------|------|----------|
| < 13 | Overview | Unmatched only, limited |
| 13–14 | Capped | All types, limited count |
| 15–17 | Full | All markers in viewport |
| ≥ 18 | Detailed | DOM markers with icons |

### Filter Panel

Filter by: match status, method, node type, operator, problem status.

## Backend Blueprints

| Blueprint | Prefix | Purpose |
|-----------|--------|---------|
| `data.py` | `/api/data` | Viewport queries |
| `search.py` | `/api/search` | Full-text search |
| `problems.py` | `/api/problems` | Problem management |
| `reports.py` | `/api/reports` | Report generation |
| `auth.py` | `/auth` | Authentication |
| `docs.py` | `/docs` | Documentation |

## Key Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/data` | GET | Viewport bounding box query |
| `/api/search` | GET | Full-text stop search |
| `/api/problems` | GET | Stop problems |
| `/api/reports/generate` | POST | Generate PDF/CSV |

## Running the Application

```bash
# Development
docker compose up -d
docker compose logs -f app

# Production
docker compose -f docker-compose.prod.yml up -d
```
