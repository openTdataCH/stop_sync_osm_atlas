# Web Application

The Stop Sync web application provides an interactive map interface for exploring and managing the ATLAS–OSM data.

## Architecture

| Layer | Technology |
|-------|------------|
| Frontend | Leaflet + Vanilla JS |
| Backend | Flask (Python) |
| Database | PostgreSQL + PostGIS |
