### HRDF ATLAS data

### Public view
HRDF is a raw format used by HAFAS (the timetable engine). We read just the parts we need to derive clean outbound/inbound direction information per ATLAS stop (`sloid`), like “City A → City B”.

What we do:
- Download and extract only the necessary HRDF files: `GLEISE_LV95`, `FPLAN`, `BAHNHOF`
- Two-pass over `GLEISE_LV95`: first find which (UIC, #ref) pairs correspond to ATLAS `sloid`s, then collect only their trips
- From `FPLAN`, extract line names and the first/last station of each target trip
- Use `BAHNHOF` to map UIC codes to human-friendly station names
- Produce unique direction tuples per `sloid` (line, direction name, direction UIC)

What it enables:
- Human-readable direction strings aligned to ATLAS stops, used in the unified routes output

Diagram (targeted parsing flow):
```
ATLAS sloids ──────────────► GLEISE_LV95 (pass 1) ──► sloid → (UIC, #ref)
                                        │
                                        ▼
                           GLEISE_LV95 (pass 2, targeted) ──► trips for needed (UIC,#ref)
                                        │
                                        ▼
                                     FPLAN ──► per-trip { line, first_stop, last_stop }
                                        │
                                        ▼
                                    BAHNHOF ──► UIC → station name
                                        │
                                        ▼
                   per-sloid unique (line, "A → B", "UIC_A → UIC_B") tuples
```
