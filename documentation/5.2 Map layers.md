# Map Layers

The interactive map provides multiple tile layer options.


## Base Maps

| Layer | URL |
|-------|-----|
| **OpenStreetMap** | `tile.openstreetmap.org` |
| **Transport** | `tile.memomaps.de` |
| **Satellite** | `arcgisonline.com` |



> [!Note]
> Beyond max native zoom, tiles are upscaled
