# GTFS ATLAS Data

GTFS (General Transit Feed Specification) provides timetable data that enriches ATLAS stops with route associations, enabling route-based matching.

## Challenge

The `stop_times.txt` file contains **100+ million rows**—too large to load into memory. We use a **two-pass streaming** approach:

```mermaid
flowchart LR
    subgraph Pass1["Pass 1: Collect"]
        S1["stops.txt"] --> F1["Filter Swiss"]
        ST1["stop_times.txt<br/>Stream"] --> T1["Relevant trip_ids"]
        T1 --> FL["First/Last stops"]
    end
    
    subgraph Load["Load"]
        TR["trips.txt"] --> FT["Filter by trip_ids"]
        RO["routes.txt"] --> FR["Filter by routes"]
    end
    
    subgraph Pass2["Pass 2: Build"]
        ST2["stop_times.txt<br/>Stream"] --> U["Unique triples<br/>stop_id, route_id, direction"]
        U --> M["Map to sloid"]
    end
    
    Pass1 --> Load --> Pass2
```

## Processing Steps

### Step 0: Filter Swiss Stops

Keep only stops where `stop_id` starts with `85` (Swiss UIC prefix) and coordinates fall inside Switzerland.

### Step 1: Pass 1 — Collect Trip Information

Stream `stop_times.txt` in 500K-row chunks to identify trips referencing Swiss stops and record first/last stops for direction naming.

### Step 2: Load Filtered Reference Data

Load `trips.txt` and `routes.txt`, keeping only rows referenced by our trip set.

### Step 3: Pass 2 — Build Unique Route Associations

Stream `stop_times.txt` again to build unique `(stop_id, route_id, direction_id)` triples.

### Step 4: Map stop_id → sloid

| Priority | Rule | Description |
|----------|------|-------------|
| 1 | **Strict** | Parse `stop_id` → match `(uic_number, local_ref)` to ATLAS `(number, designation)` |
| 2 | **Unique UIC** | If ATLAS has exactly one row for the UIC, use that `sloid` |
| 3 | **Token match** | Match `last-token(sloid)` to normalized `local_ref` |

## Output

Contributes to `data/processed/atlas_routes_unified.csv`:

| Column | Description | Example |
|--------|-------------|--------|
| `sloid` | ATLAS stop identifier | `ch:1:sloid:8503000:1` |
| `source` | Data source | `gtfs` |
| `route_id` | GTFS route identifier | `11-4-A-j25-1` |
| `route_id_normalized` | Cleaned (removes `-j2025` suffixes) | `11-4-A` |
| `direction_id` | Direction | `0` (outbound), `1` (inbound) |
| `direction_name` | Human-readable | `Zürich HB → Bern` |
