# Python Tests

This document covers the Python testing setup for the matching pipeline and backend API.

## Test Location

```
tests/
├── conftest.py          # Shared fixtures and test configuration
├── test_matching.py     # Matching pipeline unit tests
└── test_backend.py      # Backend API unit tests
```

## What is Tested

### Matching Pipeline (`test_matching.py`)

| Module | Tests |
|--------|-------|
| `matching_process/utils.py` | `haversine_distance`, `is_osm_station` |
| `matching_process/route_matching_unified.py` | `_normalize_route_id_for_matching`, `_normalize_direction_id` |
| `matching_process/exact_matching.py` | UIC-based matching logic |
| `matching_process/name_matching.py` | Name-based matching logic |

### Backend API (`test_backend.py`)

| Module | Tests |
|--------|-------|
| `backend/queries/helpers.py` | `parse_filter_params`, `optimize_query_for_endpoint` |
| `backend/blueprints/data.py` | `_parse_bbox_from_request_args` |
| `backend/serializers/stops.py` | `format_stop_data` |
| `backend/services/crypto.py` | Encryption/decryption roundtrip |
| `backend/query_builder.py` | `FilterBuilder` static methods |

## Running Tests Locally

### Using Docker (Recommended)

Run tests with the same dependencies as CI/CD:

```bash
# Run all tests
./run-tests-local.sh

# Or just Python tests
docker-compose run --rm app-dev bash -c "pip install pytest pytest-cov && FLASK_ENV=testing TESTING=true DATABASE_URI='sqlite:///:memory:' AUTH_DATABASE_URI='sqlite:///:memory:' SECRET_KEY='test-secret-key' pytest tests/ --cov=matching_process --cov=backend -v"
```

### Directly on Your Machine

#### Install Dependencies

```bash
pip install -r requirements.txt
pip install pytest pytest-cov
```

#### Run All Tests

```bash
pytest tests/ -v
```

#### Run with Coverage

```bash
pytest tests/ --cov=matching_process --cov=backend --cov-report=html -v
```

Open `htmlcov/index.html` to view the coverage report.

⚠️ **Note:** Running directly requires Python 3.11. Use Docker for consistent results.

### Run Specific Test Files

```bash
# Only matching tests
pytest tests/test_matching.py -v

# Only backend tests
pytest tests/test_backend.py -v
```

### Run Specific Test Classes or Methods

```bash
# All tests in a class
pytest tests/test_matching.py::TestHaversineDistance -v

# Single test method
pytest tests/test_matching.py::TestHaversineDistance::test_same_point_returns_zero -v
```

## CI Configuration

The `python-tests` job in `.github/workflows/tests.yml`:

1. Installs Python 3.11
2. Installs project dependencies + pytest
3. Runs `pytest tests/` with coverage
4. Uploads coverage to `python-coverage-report` artifact

Environment variables set in CI:

```yaml
FLASK_ENV: testing
TESTING: 'true'
DATABASE_URI: 'sqlite:///:memory:'
AUTH_DATABASE_URI: 'sqlite:///:memory:'
SECRET_KEY: 'test-secret-key'
```

## Python Linting

The `python-lint` CI job runs:

| Tool | Mode | Blocks CI? |
|------|------|------------|
| flake8 | `E9,F63,F7,F82` (syntax/imports) | ✅ Yes |
| flake8 | Full check | ❌ No (advisory) |
| black | `--check --diff` | ❌ No (advisory) |
| isort | `--check-only --diff` | ❌ No (advisory) |

### Run Linting Locally

#### Using Docker (Recommended)

```bash
# Run linting with same environment as CI
docker-compose run --rm app-dev bash -c "pip install flake8 black isort && flake8 . && black --check . && isort --check-only ."
```

#### Directly on Your Machine

```bash
pip install flake8 black isort

# Check for issues
flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
black --check --diff .
isort --check-only --diff .

# Auto-fix formatting
black .
isort .
```
